あなたは現実から「noclip」し、終わりのない黄色い部屋へ落ちた。
各階層で鍵となるアイテムをすべて集め、出口から次の階層へ進もう。

  • スマホ：左側ドラッグで移動、右側ドラッグで視点。「走る」は押している間ダッシュ。
  • PC：WASD移動 / マウス視点 / Shift走る / C しゃがむ / F ライト / Q 飲む / Esc 一時停止
  • 走ると足音で「何か」に気づかれる。しゃがむと静かに動ける。
  • 暗闇や「何か」の近くにいると正気が減る。アーモンド水で回復できる。
  • ライトは電池を消費する。落ちている電池で補充できる。
  • Level 1 の暗がりに浮かぶ笑顔には光を当てるな。
