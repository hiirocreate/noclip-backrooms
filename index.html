設定

あそびかた

あなたは現実から「noclip」し、終わりのない黄色い部屋へ落ちた。
階層ごとに、生き延び方も出口の見つけ方も違う。落ちているメモが手がかりになる。

  • スマホ：左側ドラッグで移動、右側ドラッグで視点。スティックを外側の輪の外まで出すと走る。近くに調べられる物があると「調べる」ボタンが出る。
  • PC：WASD移動 / マウス視点 / Shift走る / C しゃがむ / F ライト / Q 飲む / E 調べる / Esc 一時停止
  • 走ると足音で「何か」に気づかれる。しゃがむと静かに動ける。
  • 暗闇や「何か」の近くにいると正気が減る。アーモンド水で回復できる。
  • ライトは電池を消費する。落ちている電池で補充できる。
