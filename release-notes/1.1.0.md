# v1.1.0 「裏側の階層」大型アップデート

■ 階層を Backrooms の設定に沿って作り直しました
- LEVEL 0 ロビー：敵はいない。見ていない間に部屋が組み変わる。「ちらつく壁」をすり抜けて脱出
- LEVEL 1 居住区画：補給箱と停電。停電中は光に群がる「笑顔」が現れる。緑の非常灯の下が避難所
- LEVEL 2 配管の夢：開かない扉と「虚無の部屋」。先人のチョークの印と刻印「Ⅲ」を頼りに進む
- LEVEL 3 変電所：機械音で足音を隠しながら、ブレーカーを上げてエレベーターへ引き返す往復脱出
- LEVEL 4 放棄されたオフィス：掲示物から暗証番号を割り出す謎解き。窓の外は見てはいけない

■ 階層ごとの環境音とBGM（残響・緊張度で変化）
■ 「調べる」操作を追加（E キー / 調べるボタン）
■ 更新のお知らせ機能を追加
■ LEVEL 5 以降は今後のアップデートで順次追加します

※ v1.0 からの初回更新時のみ、署名が変わるため旧アプリのアンインストールが必要です
